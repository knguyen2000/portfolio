# AI-Powered Interactive Portfolio

A Streamlit web app that lets visitors explore my work through four AI agent modes — file-based context, vector RAG, recursive language modeling, and neural language autoencoding.

**Stack:** Python 3.11+ · Streamlit · Google Gemini API · ChromaDB

## Quick Start

```bash
pip install -r requirements.txt
streamlit run app.py
```
